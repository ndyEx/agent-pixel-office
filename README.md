# Agent Pixel Office

AI 코딩 에이전트(**Claude Code**, **Codex**)가 지금 무슨 일을 하는지 픽셀아트 가상 사무실에서 실시간으로 보여주는 로컬 대시보드입니다.

에이전트가 파일을 고치면 책상에서 타이핑하고, 코드를 읽으면 책장으로, 명령어를 실행하면 서버랙으로 걸어갑니다.

## 실행

Node.js 18 이상만 있으면 됩니다. 설치할 의존성은 없습니다.

```bash
npm start
# 또는
node server.js
```

브라우저에서 http://localhost:4321 을 엽니다. 포트를 바꾸려면 `PORT=5000 npm start` 처럼 실행합니다.

## 동작 원리

에이전트에 직접 붙지 않고, 에이전트가 남기는 **세션 기록(JSONL)** 을 옆에서 읽습니다.

```
에이전트가 도구 사용 → 세션 기록에 한 줄 추가 → server.js가 1초마다 새 줄만 읽어 상태 판단
→ SSE로 브라우저에 전송 → office.js가 캐릭터를 목표 위치로 이동시키며 렌더링
```

| 에이전트 | 읽는 위치 |
|---|---|
| Claude Code | `~/.claude/projects/<프로젝트>/<세션>.jsonl` (+ `subagents/`) |
| Codex | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`, 이름은 `~/.codex/session_index.jsonl` |

최근 30분 안에 **자기 활동이 있는** 세션만 표시합니다. 포크·사이드 채팅처럼 기록을 복사해 둔 세션은 새 작업을 하기 전까지 나타나지 않고, 삭제·보관된 세션은 바로 사라집니다.

## 상태와 위치

| 상태 | 계기 | 사무실에서 |
|---|---|---|
| 타이핑 | Edit / Write / apply_patch | 자기 책상, 모니터에 코드 |
| 자료 조사 | Read / Grep / 읽기용 셸 명령 | 책장 |
| 터미널 | Bash / shell | 서버랙 |
| 브라우징 | WebFetch / WebSearch / 브라우저 도구 | 책상, 파란 모니터 |
| 회의 | Agent / 서브에이전트 | 회의 테이블 |
| 생각 중 | 결과를 받고 다음 행동 결정 | 책상, 말풍선 |
| 승인 대기 | Codex: 승인 요청 이벤트 / Claude: 도구 호출 후 45초 무응답(추정) | 빨간 모니터, `!` |
| 휴식 | 턴 종료 | 소파 |

Codex 캐릭터는 검은 캡모자, Claude 캐릭터는 주황 배지를 달고 있습니다.

## 한계

- Claude Code의 승인 대기는 기록에 남지 않아 침묵 시간으로 추정합니다. 오래 걸리는 명령에서도 `!`가 뜰 수 있습니다. 정확하게 하려면 Claude Code 훅(`Notification` 등)으로 이벤트를 받아야 합니다.
- 세션 기록 형식은 각 도구의 내부 형식이라 버전이 바뀌면 일부 상태 판단이 어긋날 수 있습니다.
- 로컬 전용입니다. 서버는 `127.0.0.1`에만 열립니다.

## 구조

```
server.js          세션 기록 감시 + 상태 판단 + SSE 서버 (의존성 없음)
public/index.html  레이아웃, 세션 목록 패널
public/office.js   Canvas 픽셀아트 사무실과 캐릭터 렌더링
```
