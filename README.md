# Agent Pixel Office

AI 코딩 에이전트(**Claude Code**, **Codex**)가 지금 무슨 일을 하는지 픽셀아트 가상 사무실에서 실시간으로 보여주는 로컬 대시보드입니다.

에이전트가 파일을 고치면 책상에서 타이핑하고, 코드를 읽으면 책장으로, 명령어를 실행하면 서버랙으로 걸어갑니다.

## 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 http://localhost:4321 을 엽니다. 포트를 바꾸려면 `PORT=5000 npm start` 처럼 실행합니다.
다른 기기에서도 접속하게 하려면 `HOST=0.0.0.0` 으로 실행합니다(공개할 때는 HTTPS 터널을 앞에 두세요).

## 사람: 로그인 · 방 · 채팅

- 이름과 비밀번호로 가입·로그인하면 **방향키**로 내 캐릭터를 움직일 수 있습니다.
- 방은 **사무실 · 라운지 · 회의실** 세 개이고 옆 벽의 문으로 이어집니다. 에이전트는 사무실에만 있습니다.
- 채팅은 방마다 따로입니다. Enter로 입력, Esc로 입력 끝내기.
- 계정·로그인 토큰·채팅은 `data/office.db`(SQLite)에 저장됩니다. 비밀번호는 scrypt 해시로만 보관합니다.

## 에이전트 자세히 보기 · 알림

- 사무실 화면의 에이전트나 아래 세션 카드를 **클릭**하면 상세 패널이 열립니다. 하는 일 분포와 타임라인(도구 이름·시각)을 보여 줍니다. Esc로 닫습니다.
- 상단의 **🔔 알림** 버튼을 켜면, 다른 창을 보고 있을 때 승인 대기와 작업 완료를 데스크톱 알림으로 알려 줍니다. **🔊 소리** 버튼을 켜면 8비트 효과음도 납니다. 두 설정은 브라우저마다 따로 저장됩니다.
- 승인을 기다리는 에이전트가 있으면 탭 제목에 `(1) ❗ 승인 대기`처럼 표시됩니다.

## Claude Code 훅 연결 (승인 대기를 정확하게)

Claude Code는 승인 대기를 세션 기록에 남기지 않습니다. 훅을 연결하지 않으면 45초 동안 응답이 없을 때 승인 대기로 추정합니다. 훅을 연결하면 승인 요청이 뜨는 즉시 정확하게 표시됩니다(macOS·Linux).

```bash
npm start              # 처음 실행할 때 data/hook-token 이 만들어짐
npm run hook-config    # ~/.claude/settings.json 에 넣을 hooks 블록을 출력
```

출력된 `hooks` 블록을 `~/.claude/settings.json`에 합쳐 넣습니다. 포트를 바꿔서 실행했다면 `PORT=5000 npm run hook-config`처럼 같은 포트로 만들어야 합니다.
훅은 `hooks/claude-hook.sh`가 서버의 `/api/hook`으로 이벤트를 전달하는 방식입니다. 서버가 꺼져 있어도 Claude 작업을 막지 않습니다. 요청에는 `data/hook-token` 값이 필요해서, 외부에 공개해도 다른 사람이 상태를 조작할 수 없습니다.

## 동작 원리

에이전트에 직접 붙지 않고, 에이전트가 남기는 **세션 기록(JSONL)** 을 옆에서 읽습니다.

```
에이전트가 도구 사용 → 세션 기록에 한 줄 추가 → 서버(server/agents)가 1초마다 새 줄만 읽어 상태 판단
→ socket.io(WebSocket)로 브라우저에 전송 → 화면(public/js)이 캐릭터를 목표 위치로 이동시키며 렌더링
```

| 에이전트 | 읽는 위치 |
|---|---|
| Claude Code | `~/.claude/projects/<프로젝트>/<세션>.jsonl` (+ `subagents/`) |
| Codex | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`, 이름은 `~/.codex/session_index.jsonl` |

최근 30분 안에 **자기 활동이 있는** 세션만 표시합니다. 포크·사이드 채팅처럼 기록을 복사해 둔 세션과, Codex 앱이 다른 에이전트(Claude 등)의 대화를 가져와(import) 만든 세션은 새 작업을 하기 전까지 나타나지 않고, 삭제·보관된 세션은 바로 사라집니다.

## 상태와 위치

| 상태 | 계기 | 사무실에서 |
|---|---|---|
| 타이핑 | Edit / Write / apply_patch | 자기 책상, 모니터에 코드 |
| 자료 조사 | Read / Grep / 읽기용 셸 명령 | 책장 |
| 터미널 | Bash / shell | 서버랙 |
| 브라우징 | WebFetch / WebSearch / 브라우저 도구 | 책상, 파란 모니터 |
| 회의 | Agent / 서브에이전트 | 회의 테이블 |
| 생각 중 | 결과를 받고 다음 행동 결정 | 책상, 말풍선 |
| 승인 대기 | Codex: 승인 요청 이벤트 / Claude: 훅의 승인 알림, 훅이 없으면 도구 호출 후 45초 무응답(추정) | 빨간 모니터, `!` |
| 휴식 | 턴 종료 | 소파 |

Codex 캐릭터는 검은 캡모자, Claude 캐릭터는 주황 배지를 달고 있습니다.

## 일일 통계

오늘 에이전트가 얼마나 일했는지 두 곳에서 보여줍니다.

- **회의실 화이트보드**: 오늘 시간대별(0~24시) 도구 사용 막대(주황 = Claude, 검정 = Codex)와 총 횟수. 마우스를 올리거나 탭하면 자세한 카드가 뜹니다.
- **페이지의 "📊 오늘의 통계" 카드**: 도구 사용 횟수(어제 대비), 에이전트별 횟수·작업 시간·요청 수·세션 수, 도구 유형 비율, 시간대별 막대, 최근 7일.

| 항목 | 세는 방법 |
|---|---|
| 도구 사용 | 도구 호출 한 번 = 1회 (서브에이전트 포함) |
| 요청 | Claude: 사용자가 직접 보낸 메시지(슬래시 명령·시스템 알림 제외), Codex: 턴 시작(가져온 대화의 턴 제외) |
| 작업 시간 | 이벤트가 5분 안쪽으로 이어지는 구간의 합. 서브에이전트 시간은 부모와 겹치므로 제외 |
| 날짜 | 서버가 켜진 컴퓨터의 현지 시간 기준 |

서버는 시작할 때 최근 7일치 세션 기록을 처음부터 읽어 집계하고(한 번에 8MB씩 나눠 읽으며 "집계 중 N%"를 표시), 이후에는 새로 붙은 줄만 이어서 읽습니다. 포크로 복사된 기록은 세지 않고, 파일 위치가 아니라 세션 파일 이름으로 기억하므로 앱이 기록 파일을 다른 폴더로 옮겨도 다시 세지 않습니다. 통계에는 **횟수와 시간만** 들어가고 명령어·파일명·프로젝트 이름은 들어가지 않습니다. 기록 파일이 삭제되면 그 파일의 새 활동은 더 늘지 않지만, 이미 센 값은 서버가 켜져 있는 동안 남습니다.

## 한계

- 훅을 연결하지 않은 Claude Code 세션은 승인 대기를 침묵 시간으로 추정합니다. 그래서 오래 걸리는 명령에서도 `!`가 뜰 수 있습니다. 위의 훅 연결을 권장합니다.
- 세션 기록 형식은 각 도구의 내부 형식이라 버전이 바뀌면 일부 상태 판단이 어긋날 수 있습니다.
- 기본은 로컬 전용입니다. 서버는 `127.0.0.1`에만 열립니다.
- 외부에 공개해도 괜찮도록, 명령어·파일 경로·URL·검색어·요청 글 같은 작업 내용은 서버가 화면으로 보내지 않습니다. 화면에는 세션 이름, 프로젝트(폴더) 이름, 도구 이름, 상태, 시각, 횟수만 나옵니다. 세션 ID도 파일 경로 대신 무작위처럼 보이는 값으로 보냅니다.

## 구조

```
server.js        서버 진입점 (server/app.js 가 부품을 조립)
server/          서버: 세션 기록 감시(agents/), 통계, 로그인, DB, HTTP, socket.io
public/          화면: index.html, css/style.css, js/ (main.js가 시작점)
hooks/           Claude Code 훅 스크립트
scripts/         보조 명령 (npm run hook-config)
test/            테스트 (npm test)
data/            계정·채팅 DB, 훅 토큰 (git에 올라가지 않음)
```

파일별 역할, 데이터 흐름, "이걸 바꾸려면 어디를 고치나"는 **[ARCHITECTURE.md](ARCHITECTURE.md)** 에 정리돼 있습니다.
